About the Project

Treasure Hunt is a mobile web app where the answers to the quiz questions are hidden in real places. Head out, find the clues, and submit your answers to climb the leaderboard.

Features

  • Choose from a list of available treasure hunts
  • Answer questions one at a time
  • Location-aware answers
  • Live score and leaderboard
  • Works on any modern mobile browser
